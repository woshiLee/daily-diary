## 手机号验证码问题修复

- 问题：点击"获取验证码"显示"操作失败"
- 根本原因：`RecaptchaVerifier` 初始化时 `window.auth` 为 null，因为 Firebase 还未完全准备好
- 解决：
  1. 将 `initRecaptcha` 和 `initRegRecaptcha` 改为 async 函数
  2. 将 `switchAuthMethod` 和 `switchRegisterMethod` 改为 async 函数
  3. 在初始化前调用 `waitForFirebase()` 确保 Firebase 已就绪
  4. 修正 `RecaptchaVerifier` 构造函数参数顺序（auth 作为第一个参数）
- 添加更多 Firebase 错误码映射，方便问题诊断

## 页面切换 Bug 修复

- 问题：登录后无法点击进入同步页面
- 原因：`showSettingsPage()` 直接设置内联样式 `style.display = 'flex'`，而 `goTo()` 只操作 CSS 类，内联样式优先级更高会覆盖 CSS
- 解决：修改 `goTo()` 和 `goBack()` 函数，在切换页面时清除内联 `display` 样式，让 CSS `.page.active` 正常生效

## 云同步开关 Bug 修复

- 问题：登录后无法打开云同步开关
- 原因：`toggleSwitch('cloud')` 逻辑错误，没有检查 `userProfile.isLoggedIn`，直接假设用户未登录
- 解决：添加登录状态判断，已登录用户可以正常开启/关闭云同步，未登录用户提示先登录

## 修复登录问题

- 问题：登录后无法正常使用
- 原因：`onAuthStateChanged` 回调中没有重新加载用户数据，导致登录后显示的还是之前的数据
- 解决：在登录状态变化时，如果用户已登录，调用 `loadEntriesFromFirebase()` 重新加载该用户的数据并刷新首页
