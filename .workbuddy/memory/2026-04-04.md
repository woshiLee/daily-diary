# 2026-04-04

## Firebase照片上传功能实现

### 完成内容
- 修改`addPhoto()`函数，使用真正的文件选择器让用户上传手机照片
- 修改`renderPhotoList()`函数，支持File对象预览（使用`URL.createObjectURL()`）
- 修改`openNew()`函数，区分新建和编辑模式，记录原始照片URL
- 修改`saveEntry()`函数，实现智能照片处理逻辑：
  - 编辑模式下保留已有照片URL
  - 只上传新选择的File对象
  - 支持更新已有记录（使用`updateDoc`而非仅`addDoc`）

### Bug修复
- 修复`ref is not defined`错误：将Firebase函数（ref, uploadBytes, getDownloadURL等）暴露到window.firebaseApp对象
- 修改`loadEntriesFromFirebase()`和`saveEntry()`从window.firebaseApp获取函数

### 技术细节
- 使用隐藏的`<input type="file">`实现文件选择
- `File`对象使用`URL.createObjectURL()`创建临时预览URL
- 通过`p instanceof File`判断是否需要上传
- 使用`where`查询检查记录是否存在，决定新增还是更新

### 用户权限需求
需要更新Firebase Security Rules，允许 authenticated 用户读写
