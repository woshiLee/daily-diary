# 每日日记 Daily Diary

简约优雅的日记录应用

## 功能特性

- 📅 月视图和年视图日历
- 📸 图片和文字记录
- 😊 心情追踪
- 📱 PWA支持，可安装到手机
- 🎨 简约MUJI风格设计

## PWA安装

1. 在Safari/Chrome浏览器中打开应用
2. iOS：分享 → 添加到主屏幕
3. Android：安装 → 添加到主屏幕

## 本地运行

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

## 技术栈

- 纯HTML/CSS/JavaScript
- PWA（Progressive Web App）
- Service Worker离线缓存
